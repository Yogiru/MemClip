# MemClip — справка пользователя

Утилита «3 в 1» для Windows: **очистка оперативной памяти** +
**история буфера обмена** + **копирование текста с любых элементов экрана**.
Работает из системного трея, без окон и консоли.

## Установка и запуск

1. Положите `MemClip.exe` в постоянную папку (например, `C:\Tools\MemClip`).
2. Запустите — Windows спросит права администратора (они нужны для очистки
   памяти у всех процессов и чтения текста из приложений с любыми правами).
3. В трее появится иконка MemClip. Готово.

Автозагрузка включается галочкой в меню — создаётся задача «MemClip»
в Планировщике заданий (запуск при входе, с высшими правами, без окна UAC).

## Иконка в трее

| Действие | Результат |
|---|---|
| Левый клик | Меню истории буфера обмена |
| Правый клик | Меню настроек (сгруппировано: Память, Буфер обмена, Захват, Система) |
| Двойной клик | Немедленная очистка памяти |

## Очистка памяти

- По таймеру: интервал задаётся в меню «Интервал очистки памяти»
  (1/5/10/30/60 мин или «Вручную» — только по двойному клику и команде
  «Очистить память сейчас»).
- После очистки всплывает уведомление с количеством освобождённой памяти.
- Очищаются рабочие наборы процессов, standby-листы и файловый кеш.
- Пункт **«Очистить кэш иконок и миниатюр»** помогает, когда Windows
  показывает «белые»/старые иконки: удаляются `iconcache*.db` и
  `thumbcache*.db` из профиля; если Explorer держит эти файлы, он
  перезапускается — панель задач на секунду пропадёт и вернётся,
  открытые окна не пострадают.
- **«Проверить обновления»** — запрашивает последний релиз на GitHub;
  если версия новее — предложит открыть страницу загрузки.

## Фоновый звук

Подменю **«Фоновый звук»** в группе «Система» — онлайн-потоки для
фоновой работы (воспроизведение через Media Foundation, сторонних
программ не требуется). По умолчанию выключено и ничего не грузит:
первый пункт — **«Включить»** (`[radio] enabled=` в INI);
mfplay.dll подгружается только при первом включении.

- Выбор станции — галочкой отмечается играющая.
- **«Стоп»** — остановка; **«Тише»/«Громче»** — громкость шагом 10 %
  (сохраняется в `MemClip.ini`, `[radio] volume=`).
- Встроены: Groove Salad, Drone Zone, Fluid (SomaFM) и Radio Paradise.
- Свои станции добавляются в `MemClip.ini`, секция `[radio]`:
  ```
  [radio]
  station1=Название|https://example.com/stream.mp3
  station2=Ещё одна|http://example.org:8000/stream
  ```
  URL должен вести на прямой MP3-поток (не страницу/плейлист).
  При выходе воспроизведение останавливается автоматически.

## Тема оформления

Подменю **«Тема»** в группе «Система» — три палитры:

- **День** — светлая (по умолчанию).
- **Сумерки** — тёплая приглушённая (сепия): окна тёмно-теплые,
  а меню и заголовки остаются светлыми.
- **Ночь** — тёмная.

Выбор применяется сразу (открытые окна перерисовываются) и сохраняется
в `MemClip.ini` (`[main] theme=day|dusk|night`). Теме подчиняются окно
истории, уведомления, диалог захвата текста, редактор скриншотов, а
также меню, заголовки окон и скроллбары — в теме «Ночь» они
становятся тёмными независимо от настроек Windows. Затемнение экрана
при выделении области не меняется.

## История буфера обмена

Программа запоминает всё, что вы копируете — до 30 последних записей,
каждая со **всеми форматами** сразу:

- текст, Rich Text, HTML — вставка сохраняет форматирование
- картинки и скриншоты — с **миниатюрой-превью** прямо в меню истории,
  подпись вида `[Изображение 800x600]`
- файлы и папки, скопированные в Проводнике

История переживает перезапуск — хранится в `MemClip.dat` рядом с программой.

### Как вставить из истории

**Быстрое меню:** левый клик по иконке в трее → выбор записи. В меню также:

- **Shift+клик** — закрепить/открепить запись (закреплённые помечены ★,
  всегда сверху и не вытесняются новыми копиями);
- **Ctrl+клик** — вставить как чистый текст, без форматирования
  (отсекаются RTF/HTML — вставится только сам текст).

**Окно истории:** **Ctrl+Alt+V** (или пункт «Окно истории» в меню) —
окно со строкой поиска: набираете текст — список фильтруется. Миниатюры
картинок видны слева. Кнопки: «Вставить» (Enter или двойной клик),
«Как текст», «Закрепить»/«Открепить», «Удалить», «Отмена» (Esc).
Под текстом каждой записи видны время копирования и программа-источник
(`14:32 · notepad.exe`). Правый клик по записи открывает контекстное
меню (вставить / как текст / закрепить / **сохранить как…** / удалить),
клавиша Delete удаляет выбранную запись. «Сохранить как…» пишет картинку
в PNG, текст — в UTF-8 `.txt`, список файлов — в `.txt` с путями.

«Вставлять сразу» в меню настроек выключает автовставку — тогда запись
просто кладётся в буфер, и вы вставляете её сами через Ctrl+V.

### Дополнительно

- **Ctrl+Alt+B** — вставка без форматирования: текущее содержимое буфера
  заменяется чистым текстом и сразу вставляется в активное окно.
- **«Склеивать копии»** — несколько Ctrl+C подряд (в течение 15 секунд)
  объединяются в одну запись через перевод строки — удобно собирать
  фрагменты из разных мест в один текст.
- **Исключения по процессам** — в `MemClip.ini` в секции `[clipboard]`
  ключ `exclude=` со списком exe через `;` — буфер этих программ
  не попадает в историю: `exclude=keepass.exe;bitwarden.exe`
- **Размер истории** — `[clipboard] max=N` (5–256, по умолчанию 30);
  закреплённые записи не считаются и не вытесняются.
- **Срок хранения** — `[clipboard] keep_days=N`: записи старше N дней
  автоматически удаляются при загрузке и периодически в фоне
  (0 — выкл; закреплённые не удаляются).
- **Поиск по тексту на картинках** — картинки в истории фоново
  распознаются через OCR, и найденный текст индексируется: скриншот
  можно найти в окне истории по словам, которые на нём изображены.
  Индекс живёт в памяти и пересоздаётся при новых записях.
- «Запоминать буфер» — вкл/выкл слежение (например, на время работы
  с паролями; записи из менеджеров паролей игнорируются автоматически).
- «Очистить историю» — удаляет все записи (включая закреплённые) и
  файл `MemClip.dat`.

## Захват текста с экрана

Копирует текст там, где обычное выделение не работает: заголовки окон,
кнопки, метки, тексты ошибок, элементы браузеров и современных приложений.

### Как пользоваться

1. Наведите курсор на элемент.
2. Нажмите **Ctrl+средняя кнопка мыши** или **Ctrl+Alt+T**.
3. Откроется окно с захваченным текстом:
   - весь текст уже выделен — **Enter** или «Копировать» скопирует всё;
   - выделите мышью нужный фрагмент — скопируется только он;
   - **Esc** или «Отмена» — ничего не копировать;
   - **Ctrl+C** внутри окна тоже работает.

Скопированный текст сам попадает в историю буфера.

**Копирование URL:** **Ctrl+Alt+средний клик** по ссылке — если
захваченный текст содержит адрес (`http://`, `https://`, `ftp://`,
`www.`), URL сразу копируется в буфер без окна выбора. Если URL
не найден — всплывёт уведомление «URL не найден».

**OCR (распознавание текста с картинки экрана):** **Alt+средний клик**
или **Ctrl+Alt+O** — область элемента под курсором снимается с экрана
и распознаётся через `Windows.Media.Ocr`. Это закрывает последний
«слепой» класс: текст-картинки, игры, owner-drawn элементы.
Результат открывается в обычном окне захвата — можно выделить часть
и скопировать. Требуется установленный языковой пакет OCR Windows
(Параметры → Приложения → Дополнительные компоненты → «Распознаватель
текста» / Optical character recognition). Если пакетов нет — всплывёт
уведомление «OCR недоступен».

«Захват текста» в меню настроек включает/выключает все триггеры
(текст, URL, OCR).

## Скриншот области экрана

Аналог Lightshot: **Ctrl+Alt+S** или меню настроек → **«Скриншот
области»** — экран затемняется, протяните мышью рамку нужной области
(область остаётся яркой, рядом показывается размер в пикселях).

После отпускания кнопки рамка остаётся — её можно **подогнать**:
тянуть за края и углы — изменить размер, перетаскивание внутри —
переместить целиком, клавиши-стрелки — попиксельный сдвиг
(с Shift — по 10 пикселей). Клик вне рамки начинает новое выделение.
**Enter** фиксирует выбор и выполняет действие:

- **просто Enter** — открывается мини-редактор (как в Lightshot):
  панель инструментов сверху — **Карандаш** (свободный штрих), **Линия**,
  **Стрелка**, **Рамка**, **Текст** (клик — появляется поле ввода,
  Enter фиксирует надпись), **Размытие** (пикселизация области —
  для сокрытия приватных данных); справа палитра из 6 цветов.
  Ctrl+Z или кнопка «Назад» отменяет последнее действие (включая
  размытие), «Сбросить» возвращает исходный снимок, «Копировать» /
  «Сохранить» применяют разметку и отправляют в буфер / файл,
  «Отмена»/Esc закрывает без действий. Если включена «Вставлять
  сразу», «Копировать» ещё и вставляет результат в окно, из которого
  делался снимок;
- **Alt+Enter** — сразу в буфер, минуя редактор (PNG + битмап,
  запись попадает в историю с миниатюрой);
- **Ctrl+Enter** — область распознаётся через OCR, текст открывается
  в окне захвата;
- **Shift+Enter** — PNG сохраняется в папку `screenshots` рядом
  с программой и копируется в буфер;
- **Esc** или правая кнопка мыши — отмена.

Отдельные хоткеи без выделения области: **Ctrl+Alt+A** — скриншот
активного окна, **Ctrl+Alt+F** — скриншот всего экрана (все мониторы) —
открываются в редакторе разметки (с нажатым Shift — сразу в буфер).
**Ctrl+Alt+Shift+S** — повтор последней области: мгновенный снимок
того же прямоугольника сразу в буфер — удобно для серий скриншотов.

## Настройка горячих клавиш

Меню трея (правый клик) → **«Горячие клавиши»** → выберите действие →
в появившемся окне нажмите новую комбинацию (обязателен хотя бы один
модификатор: Ctrl/Alt/Shift/Win). Esc — отмена. Сочетания сохраняются
в `MemClip.ini` рядом с программой. Настраиваются действия:
окно истории (Ctrl+Alt+V), захват текста (Ctrl+Alt+T), вставка как текст
(Ctrl+Alt+B), OCR (Ctrl+Alt+O), скриншот области (Ctrl+Alt+S),
скриншот активного окна (Ctrl+Alt+A), скриншот всего экрана (Ctrl+Alt+F),
повтор последней области (Ctrl+Alt+Shift+S).
Мышиные жесты менять нельзя.

## Параметры командной строки

| Параметр | Действие |
|---|---|
| `MemClip.exe /clean` | Разовая очистка памяти и выход |
| `MemClip.exe /install` | Добавить задачу автозапуска в Планировщик |
| `MemClip.exe /uninstall` | Удалить задачу автозапуска |
| `MemClip.exe /aN` | Автозапуск с интервалом очистки N минут (1–120) |

## Файлы

| Файл | Содержимое |
|---|---|
| `MemClip.exe` | Программа |
| `MemClip.ini` | Все настройки: хоткеи, `[main]` — `interval_min`, `watch_clipboard`, `auto_paste`, `grab_enabled`, `mem_free_min_mb` (порог автоочистки, МБ; 0 — выкл), `lang` (auto/ru/uk/be/en), `theme` (day/dusk/night); `[clipboard]` — `merge`, `exclude`, `max`, `keep_days` |
| `MemClip.dat` | История буфера с метаданными (время, программа-источник); можно удалить для полного сброса |

## Вопросы и ответы

**Не копируется текст из какой-то программы.**
Захват идёт в три слоя (UIA → MSAA → WM_GETTEXT), плюс OCR по
`Alt+средний клик` для текста-картинок. UAC-экран и экран блокировки
недоступны — это отдельный
защищённый рабочий стол.

**Запустил, а значка в трее нет.**
Программа уже работает — вторая копия корректно закроет первую и займёт
её место. Если не появилась, проверьте скрытые значки трея.

**Картинка из истории не вставляется в чат/браузер.**
Должна вставляться — при восстановлении MemClip синтезирует PNG-формат.
Если конкретная программа не принимает — попробуйте «Вставить как» /
Ctrl+Shift+V в целевой программе.

**История стала слишком большой.**
`MemClip.dat` ограничен 30 обычными записями (закреплённые не считаются)
× 8 МБ на формат. «Очистить историю» в меню сбросит всё.

**OCR пишет «недоступен».**
В системе нет языковых пакетов распознавания. Установите: Параметры →
Приложения → Дополнительные компоненты → «Распознаватель текста»
(Optical character recognition) для нужного языка, затем перезапустите
MemClip.

**Хочу удалить программу.**
Снимите галочку «Автозагрузка» → «Выход» → удалите `MemClip.exe`,
`MemClip.ini`, `MemClip.dat`. Больше ничего в системе не остаётся.
